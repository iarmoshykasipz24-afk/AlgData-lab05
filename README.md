# Лабораторна робота 5. Сортування об'єктів

**Студент:** Ярмошик Артем

**Група:** ІПЗ-3/1

**Мова програмування:** C# (.NET 10)

## Структура

```
lab05/
└── lab5.cs   # три сортування списку студентів і спостереження за однаковими значеннями
```

## Як запустити

Потрібен встановлений [.NET SDK 10](https://dotnet.microsoft.com/download). Відкрий термінал у папці `lab05` і виконай:

```
dotnet run lab5.cs
```

## Що робить програма

1. Виводить вихідний список студентів функцією `printAll`.
2. Сортує за прізвищем за абеткою (порівняння за культурою `uk-UA`).
3. Сортує за балом від вищого до нижчого.
4. Сортує за групою, а всередині групи за балом від вищого.
5. Сортує за балом, а серед однакових балів за прізвищем за абеткою.

Для сортування використано LINQ (`OrderBy`, `ThenBy`, `OrderByDescending`, `ThenByDescending`), яке є стабільним: об'єкти з однаковим ключем зберігають свій початковий порядок.
